Challenges we ran into

What broke while wiring HashKey Chain — and how we fixed it

01Real human approval

BUG

One Foundry script = one key, so the same account proposed and approved.

FIX

Four-eyes rule in the contract (SelfApproval). Split into propose → human approve → execute guarded by verify().

02Stack too deep

BUG

execute() had too many locals; solc refused to compile, and the shell script kept going.

FIX

Extracted the dividend round into a helper (no via-ir needed) and made the script stop on any forge failure.

03Wrong Merkle root

BUG

Dividend root was anchored as the cap-table root — nobody could prove a share balance.

FIX

Separate (holder, shares) tree from our OZ-compatible Python Merkle tool.

04Surprising test failure

BUG

Access-control revert showed the test contract, not the attacker.

FIX

vm.prank was consumed by the ROLE() getter — read roles first.

05HashKey tooling

BUG

Expected explorer domain didn't resolve; SIWE backend rejects chain 133.

FIX

Verified testnet-explorer.hskchain.net; MetaMask adds HSK, sign-in falls back safely.

06Missing JSON = HTTP 200

BUG

SPA fallback served index.html for /hsk-demo.json; rebuilds wiped it.

FIX

Non-JSON → "deployment pending" state; Vite plugin keeps deployment JSON.
